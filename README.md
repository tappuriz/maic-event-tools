# MAIC Event Tools

MAICの勉強会・交流会向けイベント運営支援ツールです。LTの進行と、テーブルトークのグループ分けをブラウザだけで行えます。

## 主な機能

- 大きな表示と音声通知に対応したLTカウントダウンタイマー
- connpassの参加者管理CSVの読み込み
- 出欠ステータスが「出席」の参加者だけを対象にしたグループ分け
- 学生をできるだけ分散する4〜5名程度のグループ自動作成
- 再シャッフル時に前回同じグループだった参加者ペアをできるだけ避ける配置
- 当日の参加者追加と、運営者・司会者などの除外設定
- キャンセル者・出欠未登録者を設定画面で参考表示
- プロジェクター投影に適した全画面表示

## 使い方

1. GitHub Pagesで公開したURLをブラウザで開きます。
2. **設定・データ**タブでconnpassの参加者管理CSVを読み込みます。
3. 必要に応じて学生リスト、参加者、除外フラグを調整します。
4. **グループ分け**タブでグループ数を確認し、グループを作成します。
5. 投影時は「全画面表示」を使用します。

## データの取り扱い

- CSVの参加者データはブラウザ内でのみ処理され、外部へ送信されません。
- 学生リストは利用中のブラウザの`localStorage`に保存されます。
- 初期学生リストはGit管理外の`students.json`から読み込みます。公開リポジトリを利用する場合は、[students.example.json](./students.example.json)を参考にして各環境で作成してください。
- 参加者CSVはリポジトリへ含めません。公開リポジトリへ個人情報をコミットしないでください。

## 開発

ビルドや依存パッケージは不要です。[index.html](./index.html)をブラウザで開くか、GitHub Pagesで公開して利用できます。
